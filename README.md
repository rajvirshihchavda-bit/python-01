# Python Menu Driven Program

A simple and beginner-friendly Python console application built using loops, conditional statements, and the match-case structure.

## 📌 Project Overview

This project demonstrates:
- Menu-driven programming
- Pattern printing
- Even and odd number checking
- Use of loops in Python
- match-case statement usage

The program continuously runs until the user selects the exit option.

---

## 🚀 Features

### 1️⃣ Star Pattern Design
Displays a simple star pattern using nested loops.

Example:
text
*
***
****
*****


### 2️⃣ Even and Odd Number Checker
Checks numbers in a given range and identifies whether each number is even or odd.

Example:
text
number is 10 even
number is 11 odd


### 3️⃣ Exit Program
Allows the user to safely terminate the program.
